# TransMatch Web

Web version of the TransMatch desktop application: bank-statement upload and
extraction, manual transaction entry, data enrichment, enquiry and report
export, and user / access administration.

| Part | Technology |
|------|------------|
| `apps/web` | Next.js 16 (App Router), React 19, Tailwind CSS 4, TanStack Query |
| `apps/api` | NestJS 12 REST API, PostgreSQL (`pg`), JWT session cookie |
| `packages/shared` | Types, zod validation schemas, permission codes, blacklist matching rules |
| `packages/extraction` | Statement PDF extraction (MuPDF, Tesseract OCR), bank templates, name extraction |
| `database/` | SQL migrations and the one-off legacy data migration |

It is a pnpm workspace; Node.js 22 or later and pnpm 10 are required.

## Run it locally

```
pnpm install
pnpm dev
```

- Web: http://localhost:3200 (forwards `/api/*` to the API)
- API: http://localhost:3201/api

With no `apps/api/.env`, the API uses an embedded PostgreSQL (PGlite) stored in
`apps/api/.pgdata` and creates the schema itself, so nothing else needs to be
installed. Sign in as `superuser` / `@@Adm123` and change the password.

## Configuration

Copy `apps/api/.env.example` to `apps/api/.env` and `apps/web/.env.example` to
`apps/web/.env.local`. The settings that matter in production:

- `DB_DRIVER=postgres` and `DATABASE_URL` (Supabase connection string)
- `JWT_SECRET` (required in production)
- `API_URL` for the web app. It is read at build time.

## Database

The schema follows `ArchitectureDesign/TransMatch_RDBMS_Schema_Design_Standards.md`
and lives in the PostgreSQL schema `tm`, separate from the desktop application's
tables in `public`.

```
pnpm build
pnpm db:migrate        # applies database/migrations/*.sql that have not run yet
```

To bring over the desktop application's data, run
`database/legacy/migrate_legacy_to_tm.sql` once against the same database (for
example in the Supabase SQL editor) after `pnpm db:migrate`. It reads the old
`public` tables and leaves them untouched; read the notes at the top of the
file first.

### Combination keys

Business tables use the key pattern `PP + YY + MM + NNNNN` (for example
`TR261000001`), generated by `tm.tm_generate_combination_key()` and assigned by
the `tm_set_combination_key()` trigger. Prefix registry:

| Prefix | Entity | Prefix | Entity |
|--------|--------|--------|--------|
| US | User | BK | Bank |
| GP | Group | CS | Customer |
| RL | Role | DS | Data entry source |
| PM | Permission | BL | Blacklisted name |
| UR | User role | SP | Suspicious name |
| RP | Role permission | IB | Import batch |
| ST | Status | TR | Transaction |

Points that need a human decision under the standards:

- **The prefixes above are proposed, not yet approved.** Only `US` appears in the
  standards document.
- **Capacity.** A prefix holds 99,999 keys a month; the generator raises an error
  beyond that. `TR` (transactions) is the one that could reach it: about 250
  statements of 400 rows in one month.
- **History tables** (`TM_HIS_LOGIN_LOG`, `TM_HIS_AUDIT_LOG`) use a numeric
  identity key instead of a combination key, because of that capacity limit.
- **Month boundary** of a key follows Malaysia time.

## Access control

A user holds a role, a role belongs to a group, and a role is granted screens
with View / Create / Update / Delete rights (Administration > User Rights). The
API enforces the rights on every request; the web app only hides what a user
cannot use. Deactivating a group or role switches its rights off.

## Statement extraction

Supported templates: Public Bank, Maybank, RHB (savings/current and Reflex),
Hong Leong and UOB, each with its Islamic variant. The bank is detected by OCR
of the letterhead; the user can also pick the template. CIMB, AmBank, AEON,
Affin, BSN and Bank Muamalat statements are recognised but have no template yet.

`packages/extraction/parity` compares the output with the Python desktop
application statement by statement; see its README.

The extraction package depends on MuPDF, which is licensed under the AGPL (as
is PyMuPDF, which the desktop application used).
